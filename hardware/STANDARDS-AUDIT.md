# S.2 佈線前規範檢查（2026-10-14）

## 結論：尚未達成自動開始佈線條件

使用者已授權：規範檢查全部符合後直接佈線，不再另等位置確認。目前仍有未驗證項，不能寫成全部符合。PCB 保持 0 tracks / 0 vias。

## 選用依據與證據範圍

- 主架構選 **IPC-2221C（2023）**；官方公開目錄包含布局評估、電氣間隙、元件擺放／方向／可接近性及孔環等章節。[官方目錄](https://www.electronics.org/TOC/IPC-2221C-TOC.pdf)。目前可讀的是目錄，**沒有取得完整規範正文，不能据此完成逐條符合性判定**；章節分類不等於已讀取數值要求。
- 表面黏著焊盤設計參照 **IPC-7351B** 的適用範圍，仍需完整正文及封裝尺寸／公差作正式核對。[官方公開資料](https://www.ipc.org/TOC/IPC-7351B.pdf)。本案四個自建封裝優先使用原廠建議焊盤，不能直接宣稱 IPC 合規。
- 可立即執行的工廠條件採 [JLCPCB 製造能力](https://jlcpcb.com/capabilities/Capabilities) 與 [SMD 元件間距建議](https://jlcpcb.com/help/article/minimum-spacing-for-smd-components)。這是 DFM 檢查，不能替代 IPC 全文。
- Espressif、WIZnet、Diodes 等原廠指南仍適用；一般規範不能取代 IC 的特殊布局要求。

## 已執行與修正

| 檢查 | 結果 | 限制 |
|---|---|---|
| 通孔／SMT 屬性 | 發現並修正 11 個：10 顆 HENIPER 隔離電源及 J101 | 根因為生成器誤判 pad tuple 長度；已同步改生成器、本地封裝與 PCB |
| KiCad 幾何 DRC | 修正後 0 violations；499 unconnected items | 未連線是尚未佈線；不是製造放行 |
| DRC 規則 | 最小銅間距 0.15 mm、孔到孔 0.45 mm、孔到銅 0.28 mm；板邊 0.5 mm | 取 JLC 工藝條件及較保守專案值，並非 IPC 數值 |
| 元件本體／焊盤間距篩選 | 663 個分類封裝；11 對需精確覆核 | 以 F.Fab + pads 包圍盒保守計算；11 對皆為 U2 與周圍 0603，包圍盒 0.925 mm，相對工廠建議 1 mm。包圍盒不足不直接等同實體違規 |
| 其他封裝 | 31 個未納入上述通用 SMD 分類表 | 包含通孔、接頭、晶振等；需各自的機構／組裝審查 |
| 原理圖腳位映射 | 所有已連線腳位有對應焊盤與相同 net | 不是完整 KiCad schematic parity |
| 隔離與去耦自訂檢查 | 1.04 mm 跨域焊盤包圍盒最小距離；98 項接近程度檢查 | 不是 IPC／IEC 絕緣認證，不代表回流／高速走線通過 |

檢查程式：`scripts/check-assembly-spacing.py`；明細：`assembly-spacing-checks.json`。KiCad 數值與 PCB hash 記錄於 `layout-review-checks.json`。不得把未分類、無證據或未完成的項目視為通過。

## 尚缺的放行證據

1. 可合法使用的 IPC-2221C 完整條文（及需要引用的封裝標準）；依實際工作電壓、環境及製程選定適用條件。
2. 上述 11 對元件的精確外形／引腳／焊盤間距核對及必要修正，與其餘 31 個封裝的組裝可接近性核對。
3. 原理圖與封裝欄位一致性、插接及固定件操作空間、電源與高速區佈線可行性的佈線前審閱。

走線後才能檢查的阻抗、回流、電源迴路、熱與完整 connectivity，列為下一階段，不能以尚未走線而先宣稱通過。取得完整標準前不宣稱 IPC 全面合規，也不依「全部符合」的條件啟動佈線。
